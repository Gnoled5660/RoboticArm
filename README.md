# Description
My goal is to build a robotic arm, that can be controlled over toggle switches. The robotic arm has four axis consisting of four powerful servos. Another servo is used to open and close the hand. All this will be controlled by a single arduino.

# Motivation
I have always wanted to build a robotic arm. It was basically a longterm goal. I never dared to actually build it though since I was a little bit afraid of my actual abilities. After watching many videos about it, I figured out that I could also build a simple one. And now here I am, designing all the components, which is actually not as difficult as I thought. 

# Assembling and Wiring
Building this robotic arm isn't that difficult at all. The premade CAD files are already designed with mounting holes for the screws. It is meant to be used with the plastic servo mounts that come with the servos. Once you have screwed the plastic servo horn to mounting holes, you can put the servo and the assembled CAD file together. It's pretty much like Lego. The gripper however is a little bit difficult. Since there are no servo horns that are smaller than the spur gear, the horn will always collide with the neighbouring parts, which result into a scenario, where the servo can't rotate itself. Because of that, it was unfortunately necessary to pick a cross like horn and chop the unnecessary parts.

Wiring can also be quite frustrating, because of the amount of servos there are. I would recommend to label the cables of each of the servos, so that you know exactly which cable you are holding in your hand right now. For the servos, that are placed higher, I would recommend to use some additional jumper cables, so that everything looks clean together, when you put all the wire through the holes.
